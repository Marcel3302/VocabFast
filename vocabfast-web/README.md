# VocabForge MAX

Große offline nutzbare Englisch-Deutsch-Vokabel-Lernapp mit allgemeinen und spezialisierten Themenbereichen.

## Start

Einfach `index.html` im Browser öffnen.

## GitHub Pages

1. Repository auf GitHub erstellen.
2. Den Inhalt dieses Ordners hochladen.
3. In GitHub unter **Settings → Pages** die Veröffentlichung aus dem `main`-Branch aktivieren.
4. Als Ordner `/ (root)` auswählen.

Danach ist die App direkt als Website erreichbar.

## Hinweise

- Keine Installation erforderlich.
- Lernlisten und eigene Themen werden lokal im Browser gespeichert.
- Die App funktioniert als statische Website und eignet sich daher direkt für GitHub Pages.
