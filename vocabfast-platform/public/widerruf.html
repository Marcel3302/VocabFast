Hinweis zum Testbetrieb

Diese Seite ersetzt während der nicht-kommerziellen Testphase die bisher vorgesehene Widerrufsseite.

Derzeit kein entgeltlicher Vertrag

Solange VocabFast auf der Website als Testversion gekennzeichnet ist, werden keine echten kostenpflichtigen VocabFast-Abonnements angeboten. Pro-Preise, Stripe-Ansichten und Checkout-Abläufe dienen ausschließlich technischen Tests.

Keine echten Zahlungen

Für die Testversion sollen keine echten Zahlungen ausgelöst werden. Verwende in einer ausdrücklich als Testmodus gekennzeichneten Zahlungsoberfläche ausschließlich dafür vorgesehene Testdaten.

Späterer kommerzieller Start

Sollte VocabFast künftig kommerziell angeboten werden, werden die für Verbraucher erforderlichen Vertrags-, Preis- und Widerrufsinformationen vor einem echten kostenpflichtigen Vertragsabschluss gesondert bereitgestellt.
